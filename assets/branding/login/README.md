# Reference-style login mascot

`flower-mascot.png` is the optimized 768×512 RGBA export used by Login. It was
generated using the built-in imagegen tool with the user-supplied login reference
and `../piggypath-logo.png` as visual references. Existing branding is unchanged.
The native UI supplies all text and controls; this image contains only the mascot.
Export resizing preserves the original composition and alpha channel.

## Generation prompt

Use case: illustration-story. Asset type: transparent mascot hero artwork for a
native PiggyPath login screen. Image 1 is the exact visual target for the hero
illustration only, not an edit target for the UI. Image 2 is the existing
PiggyPath mascot identity reference. Generate ONLY the standalone hero
illustration: the cheerful coral-pink pig head/body with navy smiling curved eyes
and open smiling mouth, pink snout and subtle rosy cheeks, emerging above the
small navy oval with the white-and-green winding path. Replace the overhead coins
of the existing logo with the five yellow flowers and green stems shown in Image
1. Match Image 1's small pink heart to the right, pink excitement marks to the
left, and faint pale pink organic blob behind the pig. Faithfully match the hero
composition, friendly clean flat 2D illustration, gentle shading and
pink/navy/green/yellow palette. Wide centered composition on a square canvas,
complete artwork with even transparent margins. No UI, no text, no fields, no
buttons, no corners, no watermark. Background outside the soft pink blob must be
genuinely transparent.
